# Марк Пак — прототип личного кабинета

Кликабельный HTML-прототип кабинета складского хранения: сдача и возврат вещей, витрина грузомест, заказы, тарифы, счета и оплата. Собран на дизайн-токенах из исследования действующего сервиса, без бэкенда — все данные в `assets/js/data.js`.

**Демо:** после публикации — `https://legavaz.github.io/markpack/`

## Что внутри

| Страница | Что показывает |
|---|---|
| `index.html` | Вход по телефону и СМС (демо: любые 6 цифр), промо-блок |
| `warehouse.html` | Мой склад: карточки грузомест, фильтры, поиск, подпись, фото |
| `refund.html` | Забрать вещи: выбор мест и количества → оформление, доставка, расчёт |
| `send.html` | Сдать вещи: самопривоз с пропуском или забор груза, слоты, стикеры |
| `orders.html` | Мои заказы: активные и архив |
| `order.html?no=…` | Карточка заказа: редактирование, пропуска, состав, отмена |
| `balance.html` | Счета (юрлицо), хранение, история платежей, пример счёта |
| `prices.html` | Тарифы за м³ и другие услуги (доставка, ограничения) |
| `account.html` | Данные аккаунта, редактирование, удаление |
| `notifications.html` | Уведомления (пустое состояние) |
| `faq.html` | Помощь: аккордеон вопросов |
| `contacts.html` | Поддержка: каналы связи и форма обращения |

Демо-аккаунт — юридическое лицо (счета, тарифы за м³, стикеры). Данные вымышленные.

## Как опубликовать на GitHub Pages

Репозиторий: `https://github.com/legavaz/markpack.git`

```bash
cd prototype
git init
git add .
git commit -m "Прототип кабинета Марк Пак"
git branch -M main
git remote add origin https://github.com/legavaz/markpack.git
git push -u origin main
```

Затем в GitHub: **Settings → Pages → Source: Deploy from a branch → main → / (root) → Save**.
Через минуту сайт будет доступен по адресу `https://legavaz.github.io/markpack/`.

Альтернатива — деплой через Actions: файл `.github/workflows/pages.yml` уже добавлен, тогда в Pages выберите **Source: GitHub Actions**.

## Локальный запуск

Открыть `index.html` в браузере или поднять статический сервер (нужен для корректной работы шрифтов в некоторых браузерах):

```bash
npx serve .
```

## Ограничения прототипа

- Нет бэкенда и авторизации: сессия не сохраняется, данные живут до перезагрузки.
- Платежи и загрузка файлов — имитация (модалки и тосты).
- Часть действий-заглушек (выбор адреса, регистрация) помечена тостами.
- Не для продакшена: только демонстрация сценариев и визуала.

## Стиль

- Шрифт Manrope (400/500/600/700), акцент `#D92D2B`, фон `#F5F7FA`, карточки белые с радиусом 12.
- Сайдбар 300 px, шапка 64 px, сетка карточек от 320 px, мобильный брейкпоинт 900 px (нижняя навигация).
